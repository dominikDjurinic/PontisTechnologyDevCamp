# Četvrta domaća zadaća @ Pontis Technology DevCamp 2026

Domaća zadaća iz prvog predavanja Backend (BE1).

## Zadatak

Zadatak je bio izraditi CLI JavaScript skriptu koja asinkrono čita 3 tekstualne datoteke i broji ukupan broj riječi u pojedinoj datoteci. Skripta kao rezultat vraća ukupan broj riječi u datotekama sortiran od najvišeg prema najmanjem.

## Upute za pokretanje

- **Node.js:** `v24.11.1` (ili `v24.x`)

1. Preuzmite mapu `dz-4`
2. Otvorite terminal i pozicionirajte se u preuzetoj mapi

   ```bash
   cd dz-4
   ```

3. Pokrenite skriptu `wordCounter.js` pomoću naredbe `node` i kao argumente predajte 3 `.txt` datoteke\*

   ```bash
    node wordCounter.js first.txt second.txt third.txt
   ```

   (\* U mapi se nalaze defaultne datoteke first.txt, second.txt i third.txt koje se pozivaju ako nisu navedene druge datoteke.)

## Primjer ispisa

WORD COUNTER LIST

---

third.txt (broj rijeci): 7

first.txt (broj rijeci): 6

second.txt (broj rijeci): 4
